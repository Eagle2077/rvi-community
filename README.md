# Сообщество РВИ — прототип

Прототип закрытой соцсети для Организации развития видеоигровой индустрии (РВИ, forgamedev.ru).

- `index.html` — версия 2: чаты, поиск, люди с экспертизой и приватностью профиля, блоги и новости, аналитика, инициативы и законы на согласование, вступление по анкете и голосованию участников.
- `index-v1.html` — первая версия: лента, инициативы, заявки.

## Как это работает

Страница — один HTML-файл без сборки. Открытая на обычном хостинге (например, GitHub Pages), она работает в **демо-режиме**: данные примерные, хранятся только в браузере посетителя, роль переключается в панели сверху.

Для настоящей работы нужен сервер: общая база, вход по аккаунтам, проверка прав и приватности профилей на сервере, API для выгрузки резюме на площадки.
